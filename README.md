# Zar Safari Portfolio

Personal portfolio website for Zar Safari, built with React and deployed with GitHub Pages.

Live site path configured in `package.json`:

```visit
https://zahrasafari91.github.io/portfolio
```


## Development

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm start
```

Run tests:

```bash
npm test -- --watchAll=false
```

Build for production:

```bash
npm run build
```

Deploy to GitHub Pages:

```bash
npm run deploy
```

## Notes

- The app is configured to build for `/portfolio/`.
- The navigation uses in-page anchors for About, Work Experiences, Education, Honors & Awards, and Publications.
- Publication GitHub/reference links are placeholders where needed and can be updated in `Publications.jsx`.
